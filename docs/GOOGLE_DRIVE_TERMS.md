# AR-local Pi Backups terms of use

Effective 13 September 2026.

AR-local Pi Backups is a personal recovery tool operated by the AR-local
repository owner on their own Pi and Google Drive account. It is not a hosted
backup service accepting customer accounts. Its authorized purpose is to back
up, check and restore that owner's retained AR-local data.

Use requires the account owner's Google authorization and sufficient Drive
storage. The owner controls whether the Pi services run, retains the encryption
recovery key and manages Google account access. Existing Google service terms
continue to govern the Google account and storage service.

Successful sign-in or upload alone is not proof of a recoverable backup. The
initial backup is accepted only after repository checks and a complete cloud
restore with file hashes and database integrity checks. Later restore checks
and recorded failures are described in the
[backup documentation](GOOGLE_DRIVE_BACKUP.md).

The workflow retains previous snapshots and audit evidence. Removing backups,
revoking access or losing the encryption key can prevent recovery. There is no
promise of uninterrupted operation or recovery from an unverified snapshot.

See the [privacy policy](GOOGLE_DRIVE_PRIVACY.md) for Google data access,
storage, retention and owner controls. Questions can be directed to
[the AR-local repository maintainer](https://github.com/yanniedog/AR-local).
