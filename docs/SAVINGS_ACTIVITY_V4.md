# Savings activity v4

This opt-in producer path binds a preceding account-activity assessment to one
completed historical savings period. It uses wire version 4,
`savings_activity_calculation`, `aud-savings-activity-v1` and
`product-terms-engine-v9`. Existing v1-v3 contracts and default registry versions
remain unchanged. Supply `executable_v4_root` explicitly to the payload builder;
immutable revisions and a compatible shipped consumer are required.

Staging verifies retained original source bytes, dated applicability, structured
material reviews, assessment/application authority coverage and current routing.
Independent review binds the complete policy and authority graph, an actual
adapter/evaluator code closure and retained inputs/results, and independently
computed Fraction expectations. Approval requires bonus, base-only, unknown,
complete holdout and five actual refusal controls. Unknown individual metrics
remain unknown even when another requirement determines the combined result.
Publication rechecks approval and source state. Revocation creates a tombstone;
it never emits an empty approved product asset.

The additive 003 migration preserves populated predecessor rows, columns and
objects, with immutable preservation/schema receipts. Its unpublished draft
contained a v3-only publication constraint. The corrected draft DDL hash is
`070efdabe942b0b3f6d0abffd4507ed0fda47972e554d0be3315c22b6a6956b1`.
The former draft hash `45f8d24b81a17e326c6b49468658ebcd642eca845fedffb7331da98ce885abae`
is not silently adopted: existing stores with that marker fail closed and need
a separately reviewed migration. No live store was migrated during this work.

The retained example.invalid fixture executes the actual frozen app adapter and
v9 evaluator. It proves engineering mechanics, not bank terms, official-source
acquisition, real-account accuracy or runtime acceptance. Unsupported activity,
fees, missing historical observations and unavailable source evidence remain
explicit completion blockers. ARE2 classification must include v4 assets before
activation; this optional path is not permission to publish plaintext.
