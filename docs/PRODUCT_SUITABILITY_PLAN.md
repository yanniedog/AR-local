# Product suitability plan ownership

Consumer product selection, ranking presentation, refinance journeys,
monetisation, and app user experience are owned by
[yanniedog/AR-app](https://github.com/yanniedog/AR-app). The current app source,
tests, product plan, and issue tracker there are authoritative.

AR-local's responsibility is to provide accurate source facts: rate type and
unit, comparison and advertised rates, ongoing/introductory status, fees,
eligibility, product and tier identity, taxonomy, provenance, observation date,
and provisional/final status. It must not encode app-specific ranking or
monetisation fallbacks into production payload publication.

The former plan in this file described the retired in-repository mobile app and
is retained by Git history. Do not restore it as an active AR-local plan.
